Drawing conventions

  1. Solid lines are for objects and real light rays.
  2. Dotted lines are for virtual images and virtual rays.
  3. Real rays have arrows; virtual rays do not.
  4. One ray (not a cone of rays) is drawn from each point to the observer.
  5. If the line from an image point to the observer does not pass through the mirror, no light from that object point can reach the observer, so that image point cannot be seen.
