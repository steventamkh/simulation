Drawing rules
  1. Solid lines: objects and real rays.
  2. Dotted lines: images and virtual rays.
  3. Real rays have arrows; virtual rays do not.
  4. One ray from each point to the observer.
  5. Line misses the mirror → that point cannot be seen.
